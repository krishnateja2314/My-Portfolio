This one was built for **Diesta**, the club that runs the interdepartmental competitions at IIT Hyderabad. Our team of six put together a platform for **live event updates and result management** during the fest.

A fun behind-the-scenes fact: we originally planned a **livestreaming feature for matches** and even started building it, but had to scrap the idea due to some technical constraints. If you peek into the GitHub repo, you'll still find traces of that original plan.

To make things stupidly friendly for organisers, we used **Excel sheets as the backend data source**. Low-code, low-drama, everyone already knew how to edit a spreadsheet. The site was hosted on **Netlify**, and I handled the **domain setup** and **SEO** work.

If you Google _"Diesta IITH"_, our website ranks _above_ the Instagram page. Felt like a huge win.
